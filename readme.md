# Hospital de Equinos
Sistema Integral de Gestión Hospitalaria Veterinaria.

Proyecto académico desarrollado para la FES Cuautitlán, UNAM.

## Tecnologías
- Python
- Streamlit
- PostgreSQL
- Pandas

## Instalación
pip install -r requirements.txt

## Ejecución
streamlit run app.py

## Base de datos
El respaldo de PostgreSQL se encuentra en respaldo_hde.sql.

Configura tus credenciales en .streamlit/secrets.toml.

## Seguridad
No publiques credenciales ni archivos privados.

Proyecto en desarrollo.
